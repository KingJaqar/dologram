Local-font fallback from Phase 1: Next's build-time Google Fonts download was unavailable.
These unmodified release TTFs were copied from the repository's existing
@expo-google-fonts/inter 0.4.2 and @expo-google-fonts/jetbrains-mono 0.4.1 packages.
Inter weights 400/500/600/700 and JetBrains Mono 400 cover the shared typography tokens.
The original SIL Open Font License notices accompany the files. next/font/local serves
them from this app; neither builds nor running browsers need a Google Fonts connection.
