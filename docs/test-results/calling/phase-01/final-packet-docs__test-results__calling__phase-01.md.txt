# Calling Phase 1 execution result

2026-11-11, Asia/Manila. **Partially complete: offline Phase 1 implementation is
authored; the isolated-target V1 gate is pending.** The current Phase 1 authoring
progress is 70%. Verified calling-plan progress remains 11% because the plan only
credits a phase item after its live acceptance evidence is complete.

## Changed

- Added migration `029_calling_state_and_authorization.sql` with:
  - public `calls` and `call_participants` rows, participant-only SELECT RLS, safe
    Realtime publication membership, lifecycle invariants and history indexes;
  - private reservations, opaque room/admission state, action idempotency, rate
    windows, settings, webhook metadata, and deletion-safe cleanup/reconcile jobs;
  - service-role-only create/transition/snapshot/admission/provisioning/reconcile/
    worker/cleanup RPCs;
  - deterministic UUID lock ordering, bounded deadlines/backoff, session binding,
    epoch fencing, no-reopen terminal transitions, and Auth eligibility checks for
    `banned_until`, `deleted_at`, and `raw_app_meta_data.must_change_password`;
  - `call_worker_tick` for due expiry/duration/access-loss scans and fenced job
    claims. It performs no provider HTTP work.
- Added shared `calls` types, strict cursor history repository, exports, and public
  database table/function contract entries.
- Added `supabase/tests/calling_phase_1.sql` and the two-session
  `calling_concurrency.sql` procedure.
- Added [scheduler.md](phase-01/scheduler.md) with the target-only Cron,
  Vault, disable, and timing-measurement procedure.
- Added a secret-free baseline and scoped XML packet under
  [phase-01 context](phase-01/context.xml).

No new package dependency was added. No Expo/React Native code was touched, so the
Expo v57 documentation gate was not triggered for this phase.
